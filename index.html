Publicación automática

Con esto el botón Publicar para todos sube los datos al repositorio solo, sin que tengas que arrastrar archivos. El token se guarda únicamente en este navegador: no viaja al repositorio ni queda en el código de la página.

Sin configurar: el botón de publicar te descargará los archivos para subirlos a mano.
Cómo crear el token
  1. En GitHub: foto de perfil → Settings → abajo del todo, Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Nombre cualquiera, expiración la que prefieras (al vencer hay que renovarlo).
  4. En Repository access: Only select repositories → elige solo este repositorio.
  5. En Permissions → Repository permissions: Contents = Read and write. Nada más.
  6. Genera, copia el token y pégalo arriba. GitHub no vuelve a mostrarlo.

Reglas de la ingesta

  1. Materiales de servicio. Toda fila cuyo material empiece con S se descarta, en stock y en movimientos. Abajo de cada archivo se indica cuántas se descartaron.
  2. Stock: reemplaza. Cada corte pisa al anterior; el reporte siempre muestra la foto del último archivo cargado.
  3. Movimientos: acumula. El archivo es el historial exportado, así que solo se agregan las filas que aún no están. Volver a subir el mismo archivo no duplica nada; un archivo con más periodo suma lo nuevo.
  4. Sin tablas ni formatos. Basta el Excel con la hoja de datos: se busca la fila de encabezados en cualquier hoja, aunque no esté en la fila 1. Si falta una columna, se indica cuál y no se publica nada.

Qué hace cada botón

La clave abre esta ventana para cualquiera, pero publicar para todos exige que tu cuenta tenga acceso de edición al reporte. Es un permiso de la plataforma: no se puede dar con una clave.

  1. Publicar para todos — reescribe el reporte con el corte nuevo. Todos lo ven al abrir o recargar. Requiere acceso de edición.
  2. Ver en mi pantalla — aplica los archivos solo para ti. Sirve para revisar un corte antes de publicarlo, o para consultarlo sin tener permisos.
  3. Descargar reporte (.html) — se lleva lo que ves ahora en un archivo que abre solo, sin cuenta. Útil para adjuntarlo a un correo o pasárselo a quien sí publica.
